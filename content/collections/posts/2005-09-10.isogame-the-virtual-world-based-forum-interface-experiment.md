Several months ago, I started a project I called <a href="http://shobek.com/zaskoda/isogame/index.php">Isogame</a>. Using bits of programmer art, art from old projects, and art borrowed from <a href="http://images.google.com/">google images</a> (apologies to artists) - I built a very basic isometric map with an html interface. Using some custom <a href="http://en.wikipedia.org/wiki/Internet_forum">forum software</a> I'd developed for another project, I connect each tile to it's own thread. Then, I changed the map's tile based on the number of posts in that thread.
<div style="text-align: center;"><a href="http://shobek.com/zaskoda/isogame/index.php"><img alt="Isogame - The Virtual World Based Forum Interface Experiment" border="0" src="http://photos1.blogger.com/blogger/3475/837/400/moldbreaking.gif" style="cursor: pointer;"/></a></div>
What I have is not well refined or engaging, but it does convey a concept: "Evolve and change a virtual world using metrics based on social habits of the user." My prototype is extremely simple; there are countless directions to take the concept. For example: instead of measuring post count, we could track the <a href="http://ilps.science.uva.nl/cgi-bin/livejournal/mood">user's mood</a> and relate it to the world's weather. We could make it rain when the users are sad and sunny when they are happy.

Fun stuff...

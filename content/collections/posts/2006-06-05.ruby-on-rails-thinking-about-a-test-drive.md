<a href="http://www.rubyonrails.org/">Ruby on Rails</a> has a lot of buzz going for it lately. Most of the code I write these days is <a href="http://php.net/">PHP</a>. I've been wondering if RoR is something that could be useful for me. I'm sure that taking the time to explore a new language will only benefit me; however, I'm aweful busy doing things in PHP and I haven't had a whole lot of downtime.<br/><br/>So, I've been keeping my eyes peeled for good articles and poking around with questions. Today, <a href="http://reddit.com/">reddit</a> posted a link to <a href="http://www.everinjoy.net/165">the best Ruby on Rails piece I've seen thus far</a> - at least from a PHP programmers perspective. Most of the previous pieces I've read are attempts to debunk one language or the other. Julie does a wonderful job of writing a fair and informative piece that actually helped me understand the language and framework without making me install and learn it.<br/><br/>Ok - I must admit - I have installed RoR... I put it on a test server last week... but I haven't gotten a chance to play with it yet.<br/><br/>While RoR seems to be the Web 2.0 development platform of choice, I've been surprised to find out that there aren't any significantly well refined forums or CMS tools developed on the platform. I <a href="http://www.sitepoint.com/forums/showthread.php?t=386889">posted the question over on SitePoint</a> and a couple of folks confirmed my findings - or lack of findings. Note: check the thread if you want to get involved in a RoR bulletin board project.<br/><br/>I'm sure that developing web applications will eventually be as easy as writing up some diagrams with a minimum amount of logic to code. Until then, we just have to use the tools we have.

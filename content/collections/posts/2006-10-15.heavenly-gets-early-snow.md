<a class="imagelink" href="http://zaskoda.com/2006/10/15/heavenly-gets-early-snow/heavenly-web-cam-shot/" id="p57" rel="attachment" title="Heavenly Web Cam Shot"><img align="right" alt="Heavenly Web Cam Shot" id="image57" src="http://zaskoda.com/wp-content/uploads/2006/10/heavenly.thumbnail.jpg"/></a>While aggregating data for the new Snow Tripping website tonight, I ended up on <a href="http://www.skiheavenly.com/" title="Ski Heavenly">Heavenly's website</a>. I was pleased to see in big bold letters, "Second Snow Storm in a Week!"

The news was posted about 5 days ago. You can <a href="http://www.skiheavenly.com/audio_visual/webcams/" title="Heavenly Web Cams">check out the Heavenly Web cams</a> for an up-to-date view. I must admit, I'm getting a little worried. I'm seeing all of these snow fall reports popping up and the <a href="http://www.skiwinterpark.com/mountain/cams/index.htm" title="Winter Park Web Cam">Winter Park Web cams</a> aren't looking so white. I hope that changes between now and turkey day!

So, about that Snow Tripping site... I don't think I'm going to have anything to post for a while. I'm not even sure if I'll be able to reach my goals, but I'm enjoying the task of working on it.
